# FestManager Second Brain Index

Chào mừng bạn đến với Second Brain của **FestManager**. Đây là bản đồ tri thức dạng wiki được thiết kế để kết nối các tài liệu kỹ thuật, thiết kế và luồng xử lý của hệ thống, giúp bạn (hoặc AI trợ lý) tra cứu và cập nhật kiến thức nhanh chóng.

## 🧭 Bản đồ Tri thức (Categories)

### 🏗️ Kiến trúc & Luồng xử lý
- [[stack-overview]]: Tổng quan về stack công nghệ chính (React 19, HeroUI v3, Supabase).
- [[core-architecture]]: Luồng dữ liệu qua Services API, React Query và UI Components.
- [[auth-flow]]: Quy trình đăng nhập, bảo mật RLS và Edge Functions.

### 📦 Các phân hệ chính (Modules)
- [[module-events]]: Quản lý sự kiện, chi phí phát sinh và phân công nhân sự.
- [[module-inventory]]: Quản lý kho hàng, thiết bị và lịch sử log xuất/nhập kho.
- [[module-hr]]: Quản lý nhân sự, hợp đồng lao động và ca trực.
- [[module-clients]]: Quản lý khách hàng, phê duyệt tài khoản đăng ký trực tuyến.

### 🎨 Giao diện & Trải nghiệm (UI/UX)
- [[ui-components]]: Hệ thống UI Components xây dựng từ HeroUI v3.2 và Tailwind CSS v4.
- [[state-management]]: Quản lý local state, server state và context toàn cục (Theme, FAB, Toast).
